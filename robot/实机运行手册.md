>
> **装环境参考（从零装 WSL / usbipd / USB 设备挂进 WSL 的完整教程）**：<https://scnh0ytb81fx.feishu.cn/wiki/MBLswr5vmiUQwIkDj0ZcBVo4nQy>

## 每次启动 4 步

1. Windows PowerShell 开 Ubuntu

```powershell
wsl -d Ubuntu --cd ~/lerobot
```

2. 另开普通 PowerShell 挂设备

3. WSL 里确认两个串口谁是谁（编号会变，每次都要）

```bash
ls -l /dev/ttyACM*
```

拔掉 leader 的 USB 线再 `ls` 一次，消失的那个就是 leader。2026-10-24：**ACM0 = leader，ACM1 = follower**。

4. 进环境

```bash
conda activate lerobot
```

## 换了 USB 插口 / 从零配一遍

USB 口一换，**busid 就变**（`3-2` 变 `4-3` 这种），原来那条 attach 指的是旧口，会报找不到设备。
顺序固定为：看 → bind（管理员，一次）→ attach（每次插线都要）→ 回 WSL 确认。

1. 看现在插在哪些口

```powershell
usbipd list
```

`Connected` 段里两行 `USB-Enhanced-SERIAL CH343` 就是两条臂，看 **BUSID** 和 **STATE**。
`Not shared` → 走第 2 步；已经 `Shared` / `Attached` → 直接第 3 步。

2. bind（**每个口上的设备只需一次**，管理员 PowerShell）

```powershell
usbipd bind --busid 4-3
usbipd bind --busid 4-4
```

bind 记的是"这个口上这个设备"，所以**换了口大概率要重 bind**。bind 成功后设备进 `usbipd list` 的 `Persisted` 段，
同一个口上以后插拔都不用再 bind。

3. attach（每次插线后都要，`wsl --shutdown` 之后也要）

```powershell
'4-3','4-4','1-1','1-2' | ForEach-Object { usbipd attach --wsl --busid $_ }
```

四条 = 两条串口 + 两个相机（busid 按第 1 步看到的填）。`usbipd attach` 的 `--busid` 只收一个值，所以必须循环；
逐个写就是 `usbipd attach --wsl --busid 4-3` 这样一条一条来。

4. 回 WSL 确认

```bash
ls -l /dev/ttyACM*
sudo chmod 666 /dev/ttyACM*     # 报 Cannot open /dev/ttyACM 时补这一步
```

两条 `ttyACM0` / `ttyACM1` 都在就对了。谁是谁：拔一根 leader 的线再 `ls`，消失的那个是 leader。
2026-10-24：**ACM0 = leader，ACM1 = follower**（口固定的话每次都是这个对应关系）。

### 卡住了对照

| 现象                                        | 原因 / 处理                                             |
| ------------------------------------------- | ------------------------------------------------------- |
| attach 报设备不存在，或挂完 WSL 里没有      | 用的是旧 busid。回第 1 步看新的                         |
| `usbipd list` 里 STATE 一直 `Not shared`    | 没 bind，或者 bind 时不是管理员                         |
| 只在 `Persisted` 里出现、`Connected` 里没有 | 线没插牢 / 供电不足。两个串口同时挂，尽量走带供电的 HUB |
| WSL 里 `/dev/ttyACM` 打不开                 | `sudo chmod 666 /dev/ttyACM*`                           |
| 相机索引变了（`video0`/`video2` 对调）      | 相机也换了口，重跑下面「相机确认」那节                  |

## 跟随

```bash
lerobot-teleoperate \
  --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=zyf_follower \
  --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=zyf_leader
```

看两件事：方向对不对（反了是 leader 校准基准姿态摆反），夹爪行程够不够（不够是扳机没掰到底）。

## 推理

```bash
lerobot-rollout \
  --strategy.type=base \
  --policy.path=TrebleY/act_pickplace_v2 \
  --policy.device=cuda \
  --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=zyf_follower \
  --robot.cameras='{"overhead":{"type":"opencv","index_or_path":0,"fps":30,"width":640,"height":480,"fourcc":"MJPG"},"wrist":{"type":"opencv","index_or_path":2,"fps":30,"width":640,"height":480,"fourcc":"MJPG"}}' \
  --task="pick and place" --duration=10
```

相机名必须是 `overhead` / `wrist`，索引按相机确认那步的结果填。

## 采数据

```bash
lerobot-record \
  --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=zyf_follower \
  --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=zyf_leader \
  --robot.cameras='<把推理命令里那整段 JSON 原样贴过来>' \
  --dataset.repo_id=TrebleY/<新数据集名> --dataset.num_episodes=50 \
  --dataset.single_task="pick and place" --dataset.push_to_hub=true
```

录制中 `→` 结束本集，`←` 丢弃重录，`Esc` 停止。
已有数据集别覆盖：`pickplace_50_20260902_213020`、`pick_place_50_20260910_190133`、`pick_place_50_20260911_162829`、`advanced_pick_place_merged`、`advanced_pick_place_merged_v2`

## 校准

```bash
# follower
lerobot-calibrate --robot.type=so101_follower --robot.port=/dev/ttyACM1 --robot.id=zyf_follower

# leader
lerobot-calibrate --teleop.type=so101_leader --teleop.port=/dev/ttyACM0 --teleop.id=zyf_leader
```

leader 只能用 `--teleop.*`。重校 follower 会覆盖 `zyf_follower.json`，等于改掉模型的输入量程，之后必须重跑推理验证。

## 三条硬约束

- `teleoperate` 和 `rollout` 不能同时跑，都独占 follower 串口
- `--strategy.type=base` 不能带任何 `--dataset.*`
- 相机索引复现训练时的排列，不是让名字符合语义（训练时 overhead→0，现在也是 overhead→0）

## 关机

`Ctrl+C` → 托住机械臂（断开会掉扭矩）→ 关窗口。下次重跑上面 4 步。

## 报错速查

| 现象                             | 处理                                                                  |
| -------------------------------- | --------------------------------------------------------------------- |
| 设备少了 / Not shared            | 重跑启动第 2 步；少设备查线和供电                                     |
| `Could not connect on port ''`   | 端口变量没设，直接写死路径                                            |
| `Cannot open /dev/ttyACM`        | `sudo chmod 666 /dev/ttyACM*`                                         |
| `invalid choice: 'so101_leader'` | leader 用 `--teleop.type`                                             |
| `No calibration`                 | id 错，`find ~/.cache/huggingface/lerobot/calibration -name '*.json'` |
| `ImportError: 'datasets'`        | `cd ~/lerobot && pip install -e ".[dataset]"`                         |
| 相机维度不匹配                   | 索引反了，重做相机确认                                                |
| 动作抽搐 / 方向偏                | 先 Ctrl+C 看方向，别急着重校                                          |
